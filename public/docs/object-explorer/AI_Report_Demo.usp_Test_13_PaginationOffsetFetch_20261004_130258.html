Root Cause

The optional predicate pattern (@Param IS NULL OR column = @Param) is non-sargable and forces an Index Scan, preventing the optimizer from using an Index Seek when the parameter is provided.

Why This Matters

Sargable predicates allow the optimizer to choose efficient seek plans, reducing reads and CPU, especially as data grows or page numbers increase.

Change
Fix Steps

  • Replace the static optional predicate pattern with dynamic SQL built only from non-NULL parameters. This allows the optimizer to produce a seek plan for provided filters while still returning all rows when all filters are NULL. The full rewrite is provided below.

Expected Impact

Provided filters will use an Index Seek on Sales.Orders instead of an Index Scan, reducing logical reads and CPU for those executions. The magnitude of improvement must be measured after implementation because the current runtime sample is too small to quantify.

Code Example (Before / After)
CREATE OR ALTER PROCEDURE Demo.usp_Test_13_PaginationOffsetFetch
    @CustomerID INT = NULL,
    @StartDate  DATE = NULL,
    @EndDate    DATE = NULL,
    @PageNumber INT = 1,
    @PageSize   INT = 50
AS
BEGIN
    SET NOCOUNT ON;

    IF @PageNumber IS NULL OR @PageNumber <= 0 SET @PageNumber = 1;
    IF @PageSize IS NULL OR @PageSize <= 0 SET @PageSize = 50;
    IF @PageSize > 1000 SET @PageSize = 1000;

    DECLARE @OffsetRows INT = (@PageNumber - 1) * @PageSize;

    DECLARE @SQL NVARCHAR(MAX) = N'
        SELECT o.OrderID, o.CustomerID, c.CustomerName, o.OrderDate,
               o.ExpectedDeliveryDate, o.PickingCompletedWhen, o.LastEditedWhen
        FROM Sales.Orders AS o
        INNER JOIN Sales.Customers AS c ON c.CustomerID = o.CustomerID
        WHERE 1=1';

    DECLARE @Params NVARCHAR(MAX) = N'@CustomerID INT, @StartDate DATE, @EndDate DATE, @OffsetRows INT, @PageSize INT';

    IF @CustomerID IS NOT NULL
        SET @SQL += N' AND o.CustomerID = @CustomerID';
    IF @StartDate IS NOT NULL
        SET @SQL += N' AND o.OrderDate >= @StartDate';
    IF @EndDate IS NOT NULL
        SET @SQL += N' AND o.OrderDate < DATEADD(DAY, 1, @EndDate)';

    SET @SQL += N' ORDER BY o.OrderDate DESC, o.OrderID DESC OFFSET @OffsetRows ROWS FETCH NEXT @PageSize ROWS ONLY;';

    EXEC sys.sp_executesql @SQL, @Params,
         @CustomerID = @CustomerID, @StartDate = @StartDate, @EndDate = @EndDate,
         @OffsetRows = @OffsetRows, @PageSize = @PageSize;
END;

DECLARE @object_name sysname = 'Demo.usp_Test_13_PaginationOffsetFetch';
DECLARE @window_start datetimeoffset = DATEADD(day, -14, SYSDATETIMEOFFSET());
DECLARE @window_end datetimeoffset = SYSDATETIMEOFFSET();
DECLARE @change_time datetimeoffset = NULL; -- Set this after applying the tested change.

SELECT
    CASE
        WHEN @change_time IS NULL THEN 'current_window'
        WHEN qsrsi.end_time < @change_time THEN 'before'
        ELSE 'after'
    END AS measurement_window,
    qsp.plan_id,
    qsp.query_plan_hash,
    SUM(qrs.count_executions) AS count_executions,
    CAST(
        SUM(qrs.avg_duration * qrs.count_executions)
        / NULLIF(SUM(qrs.count_executions), 0) / 1000.0
        AS decimal(18, 2)
    ) AS weighted_avg_duration_ms,
    CAST(MAX(qrs.max_duration) / 1000.0 AS decimal(18, 2)) AS max_duration_ms,
    CAST(
        SUM(qrs.avg_cpu_time * qrs.count_executions)
        / NULLIF(SUM(qrs.count_executions), 0) / 1000.0
        AS decimal(18, 2)
    ) AS weighted_avg_cpu_ms,
    CAST(
        SUM(qrs.avg_logical_io_reads * qrs.count_executions)
        / NULLIF(SUM(qrs.count_executions), 0)
        AS decimal(18, 2)
    ) AS weighted_avg_logical_reads,
    MAX(qrs.max_logical_io_reads) AS max_logical_reads,
    MAX(qrs.last_execution_time) AS last_execution_time
FROM sys.query_store_query AS qsq
JOIN sys.query_store_plan AS qsp
    ON qsp.query_id = qsq.query_id
JOIN sys.query_store_runtime_stats AS qrs
    ON qrs.plan_id = qsp.plan_id
JOIN sys.query_store_runtime_stats_interval AS qsrsi
    ON qsrsi.runtime_stats_interval_id = qrs.runtime_stats_interval_id
WHERE qsq.object_id = OBJECT_ID(@object_name)
  AND qsrsi.end_time >= @window_start
  AND qsrsi.start_time <= @window_end
GROUP BY
    CASE
        WHEN @change_time IS NULL THEN 'current_window'
        WHEN qsrsi.end_time < @change_time THEN 'before'
        ELSE 'after'
    END,
    qsp.plan_id,
    qsp.query_plan_hash
ORDER BY MAX(qrs.last_execution_time) DESC;
